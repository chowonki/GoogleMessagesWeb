# 화면 캡처 (Windows)

영역·창·스크롤·전체 화면을 캡처하는 작은 Windows 프로그램입니다. 실행 파일 하나(`ScreenCapture.exe`)이고 설치가 필요 없습니다.

## 기능

| 기능 | 단축키 | 동작 |
|---|---|---|
| 영역 캡처 | `PrtSc` | 화면을 끌어서 지정한 부분만 캡처 |
| 창 캡처 | `Alt+PrtSc` | 마우스 아래 창이 밝게 표시되고, 누르면 그 창을 캡처 |
| 스크롤 캡처 | `Shift+PrtSc` | 영역을 끌거나 창을 누르면 자동으로 스크롤하며 찍어 긴 이미지 한 장으로 이음 |
| 전체 화면 캡처 | `Ctrl+PrtSc` | 마우스가 있는 모니터 전체를 캡처 |

- 고르는 중에 `Esc` 나 오른쪽 클릭으로 취소합니다. 스크롤 캡처는 `Esc` 로 중간에 멈추면 그때까지 찍은 부분을 결과로 냅니다.
- 캡처하면 클립보드에 복사하고, `사진\화면캡처` 폴더에 PNG 로 저장하고, 결과 창을 띄웁니다. 셋 다 주 창에서 끌 수 있고 저장 폴더도 바꿀 수 있습니다.
- 창을 닫아도 트레이에 남아 단축키로 동작합니다. 끝내려면 트레이 아이콘을 오른쪽 클릭해 `끝내기` 를 누릅니다.
- 다른 프로그램이 같은 단축키를 먼저 쓰고 있으면 버튼에 `단축키 사용 불가` 로 표시됩니다. 이때는 버튼이나 트레이 메뉴로 캡처합니다.
- 설정은 `%APPDATA%\ScreenCapture\settings.ini` 에 저장합니다.

## 스크롤 캡처가 동작하는 방식

지정한 영역 가운데에 마우스를 두고 휠을 굴린 뒤, 화면이 멎으면 찍습니다. 앞 화면과 겹치는 줄을 찾아 새로 드러난 부분만 이어 붙이고, 더 내려가지 않으면 끝냅니다.

- 위아래에 고정된 머리글·바닥글은 한 번만 들어갑니다.
- 마우스 휠로 스크롤되는 화면에서만 됩니다.
- 관리자 권한으로 실행 중인 프로그램의 창은 스크롤할 수 없습니다 (이 프로그램도 관리자 권한으로 실행하면 됩니다).
- 계속 움직이는 내용(동영상, 움직이는 광고)이 영역에 있으면 겹치는 곳을 찾지 못해 중간에 멈출 수 있습니다.
- 결과 높이는 최대 30,000 픽셀입니다.

## 빌드

Windows 에 들어 있는 .NET Framework C# 컴파일러만 씁니다. 따로 설치할 것은 없습니다.

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1          # → dist\ScreenCapture.exe
powershell -ExecutionPolicy Bypass -File build.ps1 -Test    # 이어 붙이기 검사도 함께 실행
```

`capture/` 가 바뀌면 GitHub Actions 의 `Screen capture tool` 워크플로가 같은 빌드를 돌려 `ScreenCapture.exe` 를 내려받을 수 있게 올려 둡니다.

## 구조

| 파일 | 내용 |
|---|---|
| `src/Program.cs` | 시작점 (배율 설정, 중복 실행 방지) |
| `src/MainForm.cs` | 주 창, 트레이 아이콘, 전역 단축키, 캡처 흐름 |
| `src/OverlayForm.cs` | 영역·창을 고르는 화면 |
| `src/Grab.cs` | 화면 찍기, 창 목록 |
| `src/ScrollCapture.cs` | 스크롤하며 찍기 |
| `src/Stitcher.cs` | 찍은 화면들을 한 장으로 잇는 계산 |
| `src/PreviewForm.cs` | 결과 창 (복사, 다른 이름으로 저장) |
| `src/Settings.cs` | 설정 읽기·쓰기 |
| `test/StitchTest.cs` | `Stitcher` 검사 |

컴파일러가 C# 5 까지만 지원하므로 그 이후 문법(문자열 보간 `$""`, `?.` 등)은 쓰지 않습니다.
